Aria

Save any YouTube video as an MP3 or an MP4, on your own computer. Fast, free, nothing to install.

Download for Windows
Windows 10 and 11 · about 12 MB · no installation
  1. Download and double-click it The file lands in your Downloads folder. Double-click Aria.exe — it opens in your browser.
  2. Paste the link Copy the address of the video from YouTube and paste it in. Choose MP3 for audio, MP4 for video.
  3. Press Download The file is saved in your Downloads folder, inside a folder called Aria.
The first time only
Windows shows a blue box saying “Windows protected your PC”. That is normal for small free programs: click More info, then Run anyway. Aria then takes about a minute to set itself up. After that it starts instantly.
