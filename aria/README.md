# Aria

A local web app that turns video links into MP3 or MP4 files.

```
aria.py            the whole application: http server, job queue, yt-dlp driver
web/index.html     the interface (no build step, no dependencies, EN + IT)
icon.ico           generated by ../tools/make_icon.py
version_info.txt   Windows file-properties metadata for the built .exe
```

## Running from source

Needs Python 3.9+, plus `yt-dlp` and `ffmpeg` somewhere on `PATH` (outside Windows, Aria does
not download them for you).

```bash
python aria.py           # opens http://127.0.0.1:8756 in your browser
ARIA_NO_BROWSER=1 python aria.py   # start the server without opening a browser
```

## Building the Windows executable

CI does this on every push to `main`; to do it by hand on a Windows machine:

```powershell
pip install pyinstaller
python tools/make_icon.py
pyinstaller --noconfirm --clean --onefile --windowed --name Aria `
  --icon aria/icon.ico --version-file aria/version_info.txt `
  --add-data "aria/web;web" --add-data "aria/icon.ico;." aria/aria.py
```

## Design notes

**Speed.** `--concurrent-fragments 16` fetches DASH fragments in parallel, which is the single
biggest win on long videos. MP4 output is merged with a stream copy, never re-encoded, so a
two-hour video finishes at download speed. Only MP3 spends real CPU time, since the audio has
to be re-encoded.

**Quality.** Three choices, and *Automatic* is the default so nobody has to think:

| | Automatic | Best | Smaller file |
|---|---|---|---|
| MP3 | V0 (~245 kbps), or V2 (~190 kbps) past 90 min | V0 (~245 kbps) | V5 (~130 kbps) |
| MP4 | 1080p, or 720p past 45 min | up to 1080p | 720p |

**Staying alive.** yt-dlp is updated in the background every few days (`yt-dlp -U`). A frozen
copy of a downloader stops working within months; a self-updating one does not.

**Shutting down.** The page sends a heartbeat while it is open. With no heartbeat for 150
seconds and no active download, the server exits on its own, so closing the browser tab is
enough to quit — there is no stray process and no console window to close.

**Local only.** The server binds `127.0.0.1`, and every API call must carry a random token
that is generated at startup and embedded in the served page, so nothing else on the machine
can drive it.
